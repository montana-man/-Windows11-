# -Windows11-
本程序组适用于windows系统下网卡长时间睡眠后因为PCI Express被电脑自带控制中心设置为“最大电源节省量”从而掉线的问题，仅适用于存在此类问题且自带OEM控制中心的设备（但设备无OEM控制中心也可使用，以下步骤仅代表品牌游戏本等自带OEM控制中心的设备）。
使用方法：将两个程序连同Tools文件夹复制到C盘下，管理员身份打开CMD后复制以下代码并回车执行：schtasks /create /tn "PCIe_ASPM_Off" /tr "wscript.exe \"C:\Tools\pcie_aspm_off.vbs\"" /sc onlogon /delay 0000:30 /rl highest /f
执行完毕后按Win+R输入taskschd.msc进入任务计划程序检查"PCIe_ASPM_Off"项是否注册成功。若成功则将其选中并点击"属性"，在常规一栏中勾选：使用最高权限运行，若想完全静默则可以勾选：不管用户是否登录都要运行；然后在触发器一栏中确认是否为：登录时，延迟30秒；若您的设备所属OEM自带控制中心过于弱智使得您需要每分钟纠偏则可勾选重复：每1分钟，无限期（若重复菜单不提供此数值则可选择最小间隔时间数值并手动修改为每1分钟）
上述操作完成后点击确认即可。
注：1.建议使用C盘目录下Tools文件夹（此包已提供），若需要不同路径可修改上述命令中地址部分为你实际所需地址（不建议为可移动存储介质），若您实际所需路径有文件夹带空格建议在命令中使用转义引号，也就是外层双引号+内层 \"路径\"的形式。
2.此包的效果为开机等待30秒-1分钟时自动将控制面板→电源选项中高级部分的PCI Express的链接状态电源管理的两个选项均修改为关闭并在每一分钟重复执行，为避免和系统原有的平衡电源策略冲突，建议在控制面板中新建电源计划并使用。
3.下载完压缩包后解压或移动至所需位置时若出现管理员权限要求可放心通过，本包无恶意成分，欢迎审查代码

------极其重要的部分------

本包并不建议拥有以下特质的人使用：
   *对电脑和信息技术一无所知的用户
   理由：应用此包需要对windows系统的命令提示行，任务计划程序等直接涉及系统底层操作的组件有所了解，盲目使用易引发更大问题
   *所使用系统并非Windows的任何公开发行版的用户
   理由：通常来说Linux和ARM操作系统有更优方案，若您使用的系统就是Windows但为政企定制版，请找您手中设备所属组织解决问题而不是找这个极容易被认为是恶意程序的工具包
   *钱多烧着慌只用外接网卡的用户
   理由：此工具包针对的是电脑内部自带的网卡
   *只需要省电的轻薄本用户
   理由：此工具包的原理为强行修改PCI Express的链接状态电源管理选项以对抗OEM控制中心的修改，并不代表对省电有帮助，且轻薄本通常使用板载网卡而非可购买更换的通用M.2网卡，盲目使用可能会导致一些问题的发生（若您使用轻薄本且确有需求可以在设置中勾选只有在计算机使用AC电源时才启动此任务一项后无视风险继续按说明操作）
   *台式电脑用户
   理由：此工具包仅在笔记本电脑上测试过，因为台式电脑仅存在AC供电，故并不保证在台式电脑上的使用效果，且在经济条件允许时在台式电脑使用外接网卡并不会带来额外弊端
   *所使用设备为家中长辈拥有或全家共有的用户
   理由：在此类性质设备上使用此工具包以导致长辈或家中其他人产生设备中病毒/木马的焦虑，若需使用可请家中对信息技术有较多了解的长辈审查代码并完整执行此操作说明的内容以避免不必要弹窗
   *使用Windows98以前系统的用户
   理由：本包所需的任务计划程序，WScript，高级电源设置三项内容在Windows98才完全具备，若在更早的系统上使用则无法保证效果
   *所使用设备为政企单位公发的用户
   理由：同第二条，且公发设备通常不允许随意使用CMD和改动任务计划程序
